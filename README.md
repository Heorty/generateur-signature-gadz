# info

je veux generer une application simple qui permette de créer des signatures gadz en svg et png et pdf.

Elle doit etre paramétrable et contenir uniquement l'essentiel

Une signature gadz comprend :
la prom'ss a gauche en vertical
la bande en haut
la boquette en bas
la buque et la fam'ss au milieu
les boul'ss a doite
des equerres dans les coins

le police par défaut est le clun'sois
et on doit pouvoir rajouter d'autres polices pour les buques

l'appli doit etre une simple appli web qui sera déployé sur github.io
